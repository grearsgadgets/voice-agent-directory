# VoiceAgentIndex — static AI voice agent directory

Plain HTML/CSS generated by `build.py` (Python 3 standard library only). No backend, no paid APIs.

## Update data (weekly)
1. Edit `data/platforms.json`. Each field must come from the vendor's own site. Leave a field `""` if not verified. Set `checked` to the date you checked it.
2. Run `SITE_URL=https://your-domain python3 build.py`. This regenerates `site/`, including `sitemap.xml` and `robots.txt`.

## Affiliate links
Platform links have the attribute `data-affiliate="<slug>"`. They currently point to normal vendor URLs. Once you have an affiliate URL, put it in that platform's `url`, or add a lookup in `link()` in `build.py`.
Placeholders still to fill in: the prices and contact email on `advertise.html` are marked `[TBD]`.

## Deploy for free (not done yet)
- **Cloudflare Pages:** connect the repo, set the build command to `python3 build.py`, and set the output directory to `site`.
- **GitHub Pages:** commit `site/` (or build it with an Action), then publish that folder.
